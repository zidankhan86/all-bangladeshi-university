# Changelog

All notable changes to `nexcoreit/bangladesh-universities` will be documented in this file.

## v1.0.0 - 2026-08-18

- Initial Laravel package release.
- Added configurable migrations for universities, campuses, and normalized locations.
- Added Eloquent models, relationships, query scopes, importer service, facade, and Artisan commands.
- Added JSON datasets for Bangladesh public and private universities with source and verification fields.
- Added Orchestra Testbench coverage for booting, migrations, idempotent seeding, scopes, relationships, search, facade usage, commands, and dataset validation.
